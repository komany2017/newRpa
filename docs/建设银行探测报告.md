# 中国建设银行企业网银（DemoV3 演示版）探测报告

> 探测时间：2026-11-27　探测方式：CDP 打开公开 demo 页 + 真实 demo 凭据实测
> 本报告不含任何账号、密码明文。

## 1. 登录入口

- URL：`https://b2bstatic.ccb.com/V6/DemoV3/demo_login_account.html`
- 标题：`中国建行银行企业网上银行`（原页面如此，非笔误）
- 技术栈：jQuery 1.x + 传统表单 POST，无 iframe 包裹登录区

### 登录表单

| 字段 | DOM | 类型 | 说明 |
|---|---|---|---|
| 客户识别号 | `input#CUSTOMERID` | text，maxlength=23 | 页面预填（凭据不入库） |
| 操作员代码 | `input#USERID` | text，maxlength=6 | demo 预填 999999 |
| 登录密码 | `input#LOG_PWD` | **password（普通 input）** | 无安全控件、无验证码，CDP 可直接注入 |
| 登录按钮 | `input#LOGIN_BOX_BTN` | button，初始 `disabled` | 三字段非空后由 jQuery 移除 `btn_disabled` |

### 关键机制

1. **软键盘不会弹出**：页面调用了 `showKeyBord({click_objId:"#keyboardBtn", Input_texId:"#LOG_PWD"})`，但 `#keyboardBtn` 在 HTML 中被注释掉，实际无软键盘。
2. **demo 不提交真实表单**：`btn_js_link` 的点击处理按操作员代码直接跳转：
   - `999999` → `webpage_demo/account/FN90001_manage.htm`（主管版）
   - `000002` → `FN90001_check.htm`（复核版）
   - `000001` → `FN90001_account.htm`（账户版）
3. 真实企业网银路径才走 `jsencrypt` RSA 加密到 `PWD_CIPHER` 并 POST 到 `/NCCB/NECV6B2BMainPlat`。

## 2. 业务页框架

登录后是框架页，顶部菜单 `#menu1Content` 由 `taskBar` 管理：

```js
window.taskBar.createWin(code, title, url, params, flag)
```

功能页在 `iframe#win_<code>` 内动态写入（iframe 的 `src` 是 `javascript:return false;`，内容由 `document.write` 注入）。已确认的功能码：

| code | 功能 | 页面 | 说明 |
|---|---|---|---|
| 5111 | 活期账户 | `FN00001.htm` | 内含 4 个页签 |
| 0513 | 电子回单查询 | `FN01001.htm` | 回单列表 |
| 0000 | 首页 | `FNHOME_manage.html` | 常用功能入口 |
| menuMap | 菜单地图 | `FN90051_m.htm` | 全量菜单树 |

## 3. 活期账户页（win_5111）

四个页签是 `input[type=button]`，各带一个全局函数：

| 页签 | 函数 |
|---|---|
| 账户信息 | `AccoutDetail()` |
| 实时余额 | `MultiBalanceQuery()` |
| 交易明细 | `detailQuery()` |
| 历史余额 | `HisBalanceQuery()` |

### 3.1 实时余额

- 前置条件：必须勾选数据行的 `input[name=ACC_NO]`，否则 `MultiBalanceQuery()` 弹「请选择账户」并阻塞。
- 结果表列：账号 / 账户名称 / 币种 / 行别 / 账面余额 / 冻结金额 / 可用余额 / 本日存入金额 / 本日支取金额 / 账户状态 / 账户控制状态 / 开户机构 / 透支金额 / 透支天数 / 普通业务冻结金额 / 存款司法冻结金额 / 在途业务冻结金额 / >>
- 实测首条：账面余额 `887,736.48`，可用余额 `887,736.48`，账户状态 `正常`。

### 3.2 交易明细

流程：`detailQuery()` 切到查询表单 → 填 `#StDt` / `#EdDt`（`yyyyMMdd`）→ `submitToNext()` 提交 → iframe 导航到结果页 `FN00012.htm`。

结果表列（固定顺序）：

```
0 选择 | 1 交易时间 | 2 借方(支取) | 3 贷方(收入) | 4 余额 | 5 对方户名
6 对方账号 | 7 对方开户机构 | 8 记账日期 | 9 摘要 | 10 备注 | 11 账户明细编号-交易流水号
```

实测（2015-09-01 ~ 2015-09-30）返回 2 条：结息 收 3,206.66、资金归集 付 3,206.66。

## 4. 电子回单页（win_0513）

- 查询条件：`#FLAG`（查询类型）、`#ACCT_NO`（账号）、`#BEGIN_DATE` / `#END_DATE`（`yyyyMMdd`）、`#PRINT_FLAG`、金额区间等。
- 查询按钮：`doRefresh()`。
- 结果表列：回单编号 / 交易日期 / 交易流水号 / 币种 / 借方发生额 / 贷方发生额 / 对方账号 / 对方户名 / 凭证种类 / 凭证号码 / 附件下载
- 行复选框：`input[name=KEYVALUE]`，值为回单编号。

**demo 硬限制**：`downAllN01A0A()`（下载全部）实现为 `void(0)`，「预览/打印」点击后也不产生下载或新页面。因此 demo 版**只能取回单清单，无法下载 PDF/OFD 文件**。插件 `DownBankSlip` 返回回单清单字符串并记录警告。

## 5. 插件实现要点

`plugins/ccb/CCBPlugin.cpp`：

- 登录：三字段原生 setter + `input`/`change` 事件 → 校验按钮 `disabled=false` → `click()` → 等 URL 离开 `demo_login` 且进入 `webpage_demo`，再等 `window.taskBar.createWin` 就绪。
- 取数：统一走 `taskBar.createWin` + `iframe#win_<code>`，在 iframe 内用 `contentDocument` 解析表格。余额表按**表头名**定位列（查询前后列结构不同），明细与回单按固定列序。
- alert 防护：注册 `Page.javascriptDialogOpening` 事件并 `Page.handleJavaScriptDialog{accept:true}` 自动关闭，避免 `Runtime.evaluate` 被弹窗挂起。
