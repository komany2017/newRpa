# 加密配置存储（sqlite3 + AES）

## 概述

配置不再从明文 `config.json` 读取，改为**加密 sqlite3 数据库**（`config.db`）：

- 文件本体是标准 SQLite 3 数据库，但配置内容以 AES-256-CBC PKCS7 密文存储
- 密码经 PBKDF2-HMAC-SHA256（60000 轮）派生 32 字节密钥
- 密码错误 / 密文损坏 / 表缺失 → 明确报错并拒绝启动，绝不静默读明文

## 密码来源

优先级：**环境变量 `NEWRPA_DB_PASS` > 内置默认值 `1qazxsw2A`**

```bash
# 使用非默认密码时
set NEWRPA_DB_PASS=你的密码        # Windows cmd
$env:NEWRPA_DB_PASS='你的密码'      # PowerShell
export NEWRPA_DB_PASS=你的密码      # bash
```

源码里的默认密码是用户指定的暂定值（会随 Git 公开）；如需完全保密，
部署时务必设置环境变量，并用新密码重新 `config-import`。

## 数据库结构

```sql
CREATE TABLE config(k TEXT PRIMARY KEY, v TEXT NOT NULL);
-- k = 'config_json'
-- v = base64( salt(16B) || IV(16B) || AES-256-CBC-PKCS7(配置JSON) )
```

salt / IV 每次写入随机生成，同一份 JSON 每次入库的二进制都不同。

## 迁移与工具命令

旧 JSON 文件**保留不动**作为备份，内容导入 db：

```bash
# JSON → 加密 db
newrpa.exe config-import --from config.json     --config config.db
newrpa.exe config-import --from config.ccb.json --config config.ccb.db

# 加密 db → JSON（调试用；导出文件含凭据，注意保管）
newrpa.exe config-export --config config.db --to /tmp/debug.json

# 生成默认配置库
newrpa.exe init --config config.db
```

`.vscode/launch.json` 的所有 `--config` 已改指 `.db` 文件。

## 程序接口

```cpp
namespace newrpa::util {
std::string ConfigDbPassword();                        // 当前生效密码（诊断用）
bool ConfigDbRead(const std::string& dbPath, std::string& jsonOut, std::string& errOut);
bool ConfigDbWrite(const std::string& dbPath, const std::string& jsonText, std::string& errOut);
}
```

`LoadConfig()` 内部改为从 db 读 JSON 文本再解析；`SaveDefaultConfig()` 写 db。
银行密码字段的 `enc:v1:` 二次解密仍由 `LoadConfig` 完成（密钥来自配置里的 `crypto.aesKey`）。

## 构建

- `third_party/sqlite/sqlite3.c` 直接编入 NewRpaCore（C 文件，`LANGUAGE C`）
- 根 CMakeLists 启用 `LANGUAGES C CXX`
- PBKDF2 自实现（Botan 静态库未编入 PBKDF2 模块，基于 HMAC(SHA-256)，RFC 2898 等价）

## 安全边界

- 防的是「配置文件被单独拿走后直接读出凭据」；不防本机管理员。
- 默认密码随源码公开，生产部署请用 `NEWRPA_DB_PASS` 覆盖。
- db 文件在 `build-mingw/` 下（.gitignore 覆盖），不入库。
