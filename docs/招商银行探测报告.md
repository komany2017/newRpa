# 招商银行非证书用户网银探测报告

> 探测时间：2026-11-27　探测方式：CDP 无凭据打开登录页，仅提取 DOM
> 本报告不含任何账号、密码、附加码内容。

## 1. 登录入口

- URL：`https://u.ebank.cmbchina.com/ubcoreweb/ubcore/login`
- 标题：`招商银行-欢迎界面`
- 技术栈：Ant Design（React），无 iframe
- 默认选中 Tab：`非证书用户`（另有「证书用户」Tab）

## 2. 登录表单结构

| 字段 | DOM | 类型 | 说明 |
|---|---|---|---|
| 登录名 | `input#loginName` | text，maxlength=30 | 普通输入框，CDP 可注入 |
| 登录密码 | `div.cfca_passwaord_container > #password1` | CFCA 安全控件 | **不是 input**，CDP 注入无效，需硬件键盘聚焦后输入 |
| 附加码 | `input#extraCode` | text，maxlength=4 | 普通输入框，CDP 可注入 |
| 附加码图片 | 父级 `.ant-space-item` 下的 `img[src^="data:image/svg+xml"]` | 120x42 SVG | 扭曲字符图，需 OCR 或人工识别 |
| 登录按钮 | `button.ant-btn-primary`（文本「登录」） | — | 可 JS 点击 |

## 3. 关键约束

1. **密码控件**：与北京银行 pgeCtrl 同类，合成键盘大概率被拒。工程已有 `HidKeyBoard`（硬件 HID 键盘盒子）可复用。
2. **附加码**：SVG base64 图，非标准验证码图片。工程现有 OCR 通道是超级鹰（ChaojiyingOcr），需确认其能否识别 SVG 转 PNG 后的扭曲字符；否则必须人工介入（弹窗输入）。
3. **写真凭据**：仅存于被 Git 忽略的本地配置，禁止写入源码/文档/日志。

## 4. 实测结论（2026-11-27）
- CFCA 密码控件接受 CDP char 事件（150ms 间隔 + 回读圆点补输，8/8 位可稳定输入），无需 HID 硬件盒子。
- 附加码 SVG 字符明文写在 text 节点，直接解析拼接即可，比超级鹰 OCR 更准，无需打码平台。
- 首次真实登录实测：附加码解析成功、密码输入 8/8 位，但服务端返回输入信息有误、剩余可尝试次数 9。因锁号风险已停止自动重试，插件骨架已建，登录成功率待人工确认。
- 凭据仅写入被 Git 忽略的 build-mingw 本地配置，源码/文档/日志无明文。

## 5. 待确认


- 登录密码是否可用 CDP 合成键盘（需真机实测，若失败则走 HidKeyBoard）。
- 附加码采用 OCR 自动识别还是人工弹窗介入。
- 登录后业务页（余额/流水/回单）结构尚未探测——需先成功登录。

## 附：昆仑银行密码输入问题修复（2026-11-27）

- 现象：KLB 登录无法输入密码，HID 键盘报 8 字符已发送但控件星号数为 0。
- 根因：iProtect 密码控件 `_safepass` 的 `tabindex=-1`，不在 Tab 焦点顺序里。原实现先点操作员框再发硬件 Tab，焦点跳到登录按钮，密码字符进了错误元素。
- CDP 探测确认：`Tab` 后 `activeElement=Button`；点击 `_safepass` 中心或 JS `focus()` 后 `activeElement=_safepass`（并带 `focus` class）。
- 修复：聚焦改为“鼠标点击 `_safepass` 中心为主、JS focus 兜底”；密码输入改为 CDP char 事件优先、HID 盒子回退（实测 CDP 被 iProtect 拒绝，HID 8/8 位成功）。
- 同时移除源码中的硬编码账号/操作员号/密码默认值，缺失配置时明确报错。
- 实测：`LOGIN_OK`、`Login result: ok`，用户 `张丽`。
