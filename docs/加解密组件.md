# 公共加解密组件（AES-CBC PKCS7 / RSA 签名 / Botan）

## 概述

所有银行的**登录密码、证书密码**统一支持加密存储，配置文件中不再需要明文。
实现基于 **Botan 3.9.0 静态库**（`third_party/botan/`，mingw64 x86_64 编译）：

- 对称加密：**AES-256-CBC + PKCS7 Padding**
- 非对称签名：**RSA-2048 + PKCS#1 v1.5 + SHA-256**（输出 base64）

## 密钥配置（全部来自 config.json 顶层 `crypto` 段）

```jsonc
"crypto": {
  "aesKey": "<64 位 hex = 32 字节 AES-256 密钥>",
  "rsaPrivateKeyFile": "E:/.../build-mingw/bin/keys/rsa_private.pem",  // PKCS#8
  "rsaPublicKeyFile":  "E:/.../build-mingw/bin/keys/rsa_public.pem"    // X.509 SPKI
}
```

- AES 密钥**直接配置在 config.json**（不再从 crypto.key 文件读取）
- RSA 公钥/私钥**从配置指定的 PEM 文件路径读取**
- 这些文件都在 `build-mingw/` 下（已被 .gitignore 忽略），不入库

## 密文格式

```
enc:v1:<base64( randomIV(16B) || AES-256-CBC-PKCS7(plain) )>
```

- IV 每次加密随机生成，拼在密文头部一起存，无需单独保存
- 密文带 `enc:v1:` 前缀，与明文密码完全兼容（无前缀原样放行）

## 配置加载（自动解密）

`LoadConfig()` 解析每家银行的 `password` / `certPassword` 字段时，
凡带 `enc:v1:` 前缀的值自动用 `crypto.aesKey` 解密成明文再交给插件
（只进内存，不落日志）。插件代码零改动。

## CLI 用法

```bash
# ---- AES 密码 ----
newrpa.exe encrypt --value "<明文密码>"          # → enc:v1:...（密钥取 config crypto.aesKey）
newrpa.exe decrypt --value "enc:v1:..."          # → 明文（自检）

# ---- RSA 密钥对 ----
newrpa.exe keygen-rsa [--bits 2048]              # 生成 PEM 文件到 config 指定路径

# ---- RSA 签名 / 验签 ----
newrpa.exe sign --value "待签名数据"              # → base64 签名（用 config 私钥）
newrpa.exe verify --value "待签名数据" --signature "<base64>"   # → VERIFY_OK / VERIFY_FAIL
```

`--config FILE` 指定配置文件（默认 ./config.json），密钥/密钥文件路径均从该文件读取。

## 代码接口（core/include/newrpa/crypto/Crypto.h）

```cpp
namespace newrpa::crypto {
// 摘要
std::string Md5(const std::string& s);      // 超级鹰 pass2（自实现）
std::string Sha256(const std::string& s);   // Botan

// AES-CBC PKCS7 原语（key 32B，iv 16B，返回/输入 base64）
std::string AesCbcPkcs7Encrypt(const std::string& plain, const std::string& key, const std::string& iv);
std::string AesCbcPkcs7Decrypt(const std::string& cipherB64, const std::string& key, const std::string& iv);

// AES 密钥与密码封装
std::string ParseAesKeyHex(const std::string& hex);                    // 64 hex → 32B
bool IsEncryptedPassword(const std::string& s);
std::string EncryptPassword(const std::string& plain, const std::string& aesKeyRaw);
std::string DecryptPassword(const std::string& stored, const std::string& aesKeyRaw);

// RSA 签名 / 验签 / 密钥生成
bool RsaGenerateKeyPair(const std::string& privatePemPath, const std::string& publicPemPath, size_t bits = 2048);
std::string RsaSign(const std::string& data, const std::string& privatePemPath);
bool RsaVerify(const std::string& data, const std::string& signatureB64, const std::string& publicPemPath);
}
```

## 构建接线

- 实现文件：`core/src/crypto/Crypto.cpp`（编入 NewRpaCore.dll）
- 静态库：`third_party/botan/lib/libbotan-3.a`（PRIVATE 链接进 core；`lib/` 被 .gitignore 忽略）
- 所需 Botan 模块：aes / cbc / pkcs7 / base64 / system rng / sha2_32 / rsa / pkcs8 / x509
- Botan 3.x 头文件要求 C++20，工程根 `CMakeLists.txt` 已全局 `CMAKE_CXX_STANDARD 20`

## 安全边界

- AES 密钥与 RSA 私钥都在本机 config/keys 目录，防的是「配置被单独拿走/日志泄露」，
  不是防本机管理员。密钥丢失 = 数据不可恢复。
- **编译注意**：Crypto.cpp 的 RSA 模板实例化内存开销较大，若 `-j4` 并行编译失败，
  用 `mingw32-make -j1` 单线程重编即可。
